🚗 Smart Parking Lot Management System

📌 Project Overview

The Smart Parking Lot Management System is a Java-based console application designed to manage vehicle parking operations efficiently. It allows users to park vehicles, generate tickets, calculate parking fees, and monitor parking slot availability.

✨ Features

- Park cars and bikes.
- Automatic ticket generation.
- Parking slot availability tracking.
- Automatic parking fee calculation.
- Vehicle entry and exit management.
- Exception handling for invalid tickets and full parking.
- File handling to maintain parking records.
- Multithreading for background parking status monitoring.

🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Exception Handling
- File Handling
- Multithreading
- Collections Framework

🚀 How to Run

Method 1: Using Batch File

1. Download or clone this repository.
2. Open the project folder.
3. Double-click "Run_Parking.bat".

Method 2: Using Terminal

Compile the Java file:

javac ParkingLotSystem.java

Run the application:

java ParkingLotSystem

📂 Project Files

- "ParkingLotSystem.java" – Main Java source code.
